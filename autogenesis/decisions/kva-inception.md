## Decision

The control function that evaluates discussion branches is named **KVA** — Knowledge Variance Authority.

It decides keep / expand / terminate against the discussion’s original objective so the graph does not branch out of control or collapse into an infinite loop.

## Rationale

The working metaphor was Marvel’s **Loki** and the **TVA** (Time Variance Authority): a body that polices branching timelines so the multiverse does not fall out of control.

That analogy coined the term. TVA is the wrong expansion here (this is knowledge, not time), so the operational name is KVA. The Loki / TVA origin stays in this note so later readers can recover the metaphor.

## Alternatives considered

- Keep calling it TVA in the skill — rejected; the acronym would confuse anyone who does not have the show in mind, and it names the wrong domain.
- Drop the metaphor entirely — rejected; the branching / police / collapse picture is how the control layer was invented.

## Consequences

- Skill body, plan pins, and user-facing language say KVA.
- This page remains the inception pointer to TVA and Loki.
- KVA operating rules (exact criteria, cadence, terminate encoding) stay a parked residual until designed.
